# DSH SuperTerminal

在 DSH 对话旁打开 **Side Terminal**，选择智能体开始一项任务。需要更多空间时展开工作台，自由分屏，并让终端助手围绕你选中的任务提供建议。

## 开始使用

当前支持 **macOS、Node.js 24+ 和官方 DSH 0.1.1-rc.2**。暂不支持 Windows、远程终端或其他 DSH 版本。

安装 alpha.6，然后重启所选 DSH 配置：

```sh
dsh plugin --profile web add https://github.com/Harzva/dsh-superterminal/releases/download/v0.1.0-alpha.6/harzva-dsh-terminal-0.1.0-alpha.6.tgz
```

在 DSH 输入栏点击 **终端**，或输入 **/terminal** 并选择“打开终端”。从旧版 DSH Terminal 升级时继续使用同一插件，无需额外安装第二份。

## 在对话旁开始工作

Side Terminal 默认打开在 DSH 右侧详情栏，拖动栏边缘即可调整宽度。点击标题栏的 **工具详情** 可返回 DSH 原有的命令输出和工具详情；点击 **×** 收起侧栏，任务继续运行。

需要更多空间时点击 **展开工作台**，完成后点击 **回到侧边**，仍是同一组终端。空白对话或窗口太窄、无法显示右侧详情栏时，终端会先以浮层打开。

Side Terminal 提供两种关联方式：

- **绑定当前对话**：每个对话有自己的终端工作台。切换对话时，显示对应的终端；原来的任务继续运行。
- **独立工作台**：首次打开时沿用所选对话的工作区与权限，之后不随对话切换。适合需要持续查看的开发服务、检查任务或智能体。

切换关联方式会切换工作台，不会迁移正在运行的任务。绑定对话也不会自动把聊天内容交给终端中的智能体。

点击 **新建终端**，在智能体目录选择 Shell、Codex、Claude Code、Kimi、Pi 等本机工具。其他启动命令可从“使用其他命令”输入。点击终端标题可以命名任务，例如“修复登录问题”。每个工作台最多打开 12 个终端。

## 安排与恢复你的工作台

- **自由分屏**：选择双栏、主次布局、六格或十二格，也可以继续拆分窗格。
- **拖动调节**：拖动分隔线调整大小，双击均分；放大单个窗格以专注工作。
- **收起终端**：点击窗格上的 **−**，任务继续运行。通过“已收起”列表可以再次显示。
- **结束任务**：点击窗格上的 **×**，确认后停止该任务。Side Terminal 顶部的 **×** 只收起整个侧栏。

任务名称、智能体选择和布局保存在当前浏览器中，再次打开同一工作台时可恢复。仍在运行的终端会重新显示；必要时点击 **接管输入** 继续操作。

关闭或重启 DSH 会结束其中的终端进程。原进程已不存在时，页面保留任务记录；点击 **重新启动** 会打开一个新终端，不会继续旧进程，也不会自动恢复智能体之前的任务。部分历史画面可能无法完整恢复。

## 助手知道正在帮助哪个任务

先点击一个终端，再打开终端助手。助手顶部的 **正在帮助** 和结果中的 **建议用于** 会标明目标任务，方便你核对。

描述目标或粘贴报错后，点击 **生成建议**。也可以在终端中选中一段输出，预览后勾选 **附上这段输出**，再生成建议。未勾选的内容不会随请求发送。

建议中的命令可以复制，也可以点击 **填入草稿** 放到目标终端的“待发送草稿”中。草稿不会输入到终端或自动执行。请先检查内容和终端当前状态，再复制、粘贴；智能体的聊天输入框与 Shell 命令行用途不同。

切换目标终端后，助手会切换到对应任务，不会把上一项任务的建议填入另一个终端。

## 把下一步交给搭档

选择一个来源终端，点击 **交给 Agent**。填写任务目标与完成判据，选择接收者；如需分享终端内容，先选择文字，再勾选并预览摘录。

当前后台任务支持 **Pi Agent、piagent 和 Codex**。它们使用当前工作区的独立配置，需先完成登录或模型设置。其他 CLI 仍可在原生终端中交互使用。Codex 后台任务会先检查该工作区的 Codex 登录；仅配置自定义模型服务、没有 Codex 登录记录的用法，当前请通过终端交互使用。

提交后会建立独立的后台任务，来源终端继续保留。协作记录展示来源、执行者、运行状态和返回结果；长结果可展开或复制全文，提交后会直接定位到新任务。**已返回 · 待验收** 表示收到完整的 Agent 结果，需要结合目标核对成果。

勾选 **完成后将结果送回关联对话**，结果会加入发起任务的 DSH 对话，等待该对话处理。切换页面不会改变目的地；独立工作台的任务回到它自己的会话。未勾选时，也可以在结果卡片点击 **送回对话**。回传状态不确定时，可点击 **核对回传**，同一任务不会重复发送消息。

同时最多运行 2 项后台任务，每个会话保留最多 32 条交接记录。可单独停止任务；重启后未完成的任务会保留中断记录，不会自动重跑。交接不会接管来源终端的键盘，也不代表继续接收 Agent 的旧会话。

## 账号与配置

智能体目录可搜索本机工具，查看可识别的版本、使用配置和安装详情。

Codex、Claude、Kimi 和 Pi 在当前工作区使用独立配置。即使你已在其他终端登录，在这里首次使用仍可能需要重新登录。其他工具使用本机配置，并遵守 DSH 的访问权限。

“已安装”表示检测到了启动程序，不代表已登录或有可用额度。账号、套餐、剩余额度和智能体连接状态尚未自动查询，请打开相应智能体查看。部分安装方式无法读取版本号，会显示“版本未识别”。

工作区中的 `.dsh-terminal` 保存本地运行数据，请勿提交或分享；使用中的数据目录也不应删除。

## 智能建议与隐私

点击 **生成建议** 时，终端助手使用 DSH 已配置的模型，发送本次输入、所选终端的运行状态，以及你明确勾选的输出摘录。它不会自动读取其余终端内容、对话历史、工作区文件或智能体登录凭据。模型费用按所选服务的计费规则计算。

浏览器只保存恢复工作台所需的名称、布局和关联信息，不保存终端输出、助手问题或草稿。

交接任务的目标、完成判据、显式分享的摘录和返回结果保存在 DSH 本地存储中。提交任务时会把这些选定材料交给接收 Agent；回传对话会发送任务与结果，不附带其余终端历史。

安装 **DSH Supervisor** 后，可在工作台查看它对当前对话的建议。任务回传后，来源、执行者、目标和结果会进入关联对话。

直接读取终端协作状态的 Supervisor 适配已在隔离环境验证，**尚未包含在公开 Supervisor 0.2.4 中**；本包不会替换或升级 Supervisor。适配接口提供任务目标、完成判据、来源与执行者、运行及回传状态，不提供原始终端输出。正常返回和退出码 0 都不代表任务已经验收。

## 使用提示

- 连接中断时会暂停输入并尝试重连；尚未确认送达的输入不会自动重发。
- 当前为 Alpha 版本，尚不包含 Harvis 接管、任意 CLI 的后台协议适配或智能体任务的自动续接。
- 升级 DSH 前，请先确认 SuperTerminal 是否支持目标版本。

问题与反馈：[GitHub Issues](https://github.com/Harzva/dsh-superterminal/issues)。
