# DSH SuperTerminal — Logo concepts

Four original vector concepts for the DSH SuperTerminal identity. These are alternatives for selection; the application logo has not been replaced.

| SVG | Character | Idea |
| --- | --- | --- |
| [01-mimi-cat.svg](01-mimi-cat.svg) | Mimi · 终端猫 | A curious kitten with a command-prompt face. Recommended for a recognizable, friendly app identity. |
| [02-pip-bot.svg](02-pip-bot.svg) | Pip · 小助手 | A rounded robot companion with a cursor antenna. |
| [03-duo-buddies.svg](03-duo-buddies.svg) | Duo · 并肩搭档 | Two different terminals working together. |
| [04-sprout.svg](04-sprout.svg) | Sprout · 冒芽终端 | A growing idea represented by a seed-shaped terminal. |

Open [index.html](index.html) for selection, light/dark backgrounds, 16/24/32/48 px comparisons and a sidebar placement example. [Download all four SVGs](dsh-superterminal-logos.zip).

Each logo has a transparent background, a `160 × 160` viewBox, accessible title/description, editable paths, and no fonts or external dependencies. Colors: ink `#182E2A`, mint `#BDE8D4`, cream `#F6DBA6`, coral `#F2ADA8`. Full-color marks are intended for app UI and larger uses; final monochrome, tiny favicon and store icon variants can follow the selected direction.
